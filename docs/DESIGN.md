# Totoya — diseño / design

A static website (GitHub Pages) with a monthly calendar of leisure activities in
Bogotá for a 75-year-old woman ("Totoya") who loves **art, painting and dance**.
Family members also use the site to pick events and take her.

All user-facing text is **Spanish** (Colombia). Code/comments in English.

## Decisions (from the planning session)

| Topic | Decision |
|---|---|
| Hosting | Public repo `OscarSmallenbroek/totoya-website`, GitHub Pages deployed by Actions. No backend. |
| Privacy | Only the nickname "Totoya". No full name, no address. Home base only as "Bella Suiza, Usaquén". |
| Language | Spanish only. |
| Audience | Her (tablet, big text, high contrast) + family (phones). |
| Activity kinds | `asistir` (exhibitions, concerts, dance shows, theatre, cinema) and `participar` (workshops/classes, esp. for persona mayor). Different colours. |
| Mobility | Uses a cane, wheelchair for longer distances, ~300 m walking. **Show everything** with an accessibility note; she decides. Only drop events that are clearly hikes / long walks / outside Bogotá. |
| Location | Inside Bogotá only. Home: Bella Suiza, Usaquén (≈ 4.7040, -74.0330). North = "cerca de casa". Centre is fine (taxi). Outside Bogotá (Chía, La Calera, Zipaquirá, …) → excluded. |
| Time | Evening events included but flagged 🌙 (start ≥ 18:00). |
| Price | Paid allowed; show price; "Gratis" filter. |
| Per-event actions | WhatsApp share (deep link to the event), "Agregar a Google Calendar" (template URL, no auth), "Cómo llegar" (Google Maps search URL). |
| Not wanted | Printable month view, claim/"who takes her" feature, other languages. |
| Updates | GitHub Action weekly (Monday ~05:00 Bogotá = 10:00 UTC) + `workflow_dispatch`. |
| AI filter | **Ollama Cloud API** (`https://ollama.com/api/chat`, `Authorization: Bearer $OLLAMA_API_KEY`). Default model `gemma4:31b`, fallback `gpt-oss:20b`. Available: gemma4:31b, gpt-oss:120b, gpt-oss:20b, nemotron-3-nano:30b, nemotron-3-super, nemotron-3-ultra. If key missing / API fails / quota hit → keyword fallback classifier, site still updates. |

## Repository layout

```
config/settings.yml      models, horizon, home coords, keyword lists
config/sources.yml       list of sources (id, name, url, enabled) — family can edit on github.com
config/places.yml        hand-curated permanent places + recurring things (free Sundays…)
scraper/                 Node 20+ ESM pipeline (deps: cheerio, yaml only)
  run.mjs                orchestrator: scrape → normalise → classify → merge places → write JSON
  lib/                   shared helpers (http fetch w/ retry+UA, dates, ids, ollama client, keyword classifier)
  sources/<id>.mjs       one scraper per source id from sources.yml
site/                    static frontend (no build step, vanilla HTML/CSS/JS)
  index.html, styles.css, app.js
  data/events.json       generated by the pipeline (committed sample: data/events.sample.json)
.github/workflows/update.yml   weekly scrape + deploy to Pages
```

## Contract 1 — scraper module interface

Each `scraper/sources/<id>.mjs` exports:

```js
/** @returns {Promise<RawEvent[]>} */
export async function scrape(ctx) { ... }
```

`ctx` = `{ fetchText(url, opts?) → Promise<string>, fetchJson(url, opts?) → Promise<any>, log(...args), now: Date, horizonDays: number }`.
`fetchText/fetchJson` add a browser-like User-Agent, a 20 s timeout and 2 retries. Scrapers must
not throw for a single bad item — skip it and `ctx.log` the reason. If the whole source fails,
throw; the orchestrator catches it and carries on with the other sources.

Only return events whose dates overlap `[now, now + horizonDays]` (default 75 days).

```ts
type RawEvent = {
  source: string;        // source id, e.g. "banrep"
  title: string;
  url: string;           // absolute link to the event page (or listing page if none)
  start: string;         // "YYYY-MM-DDTHH:mm" (Bogotá local time, no offset) or "YYYY-MM-DD" if no time
  end?: string;          // same formats; for exhibitions this is the closing date
  venueName?: string;
  address?: string;
  priceText?: string;    // as published, e.g. "Entrada libre", "$20.000"
  description?: string;  // plain text, trimmed to ≤ 1500 chars
  tags?: string[];       // categories the source itself provides
  image?: string;        // absolute image URL if easily available
};
```

## Contract 2 — `site/data/events.json` (what the frontend reads)

```ts
type EventsFile = {
  generatedAt: string;           // ISO timestamp
  classifier: "ollama" | "keywords" | "mixed";
  events: Event[];
  places: Place[];               // permanent places ("siempre disponible")
};

type Event = {
  id: string;                    // stable: sha1(source|url|start) first 12 hex chars
  title: string;
  summary: string;               // ≤ 220 chars, Spanish, friendly
  kind: "asistir" | "participar";
  category: "arte" | "pintura" | "danza" | "musica" | "teatro" | "cine" | "naturaleza" | "otro";
  span: "single" | "range";      // range = exhibition / multi-week thing (shown in a separate strip, not every day cell)
  start: string;                 // "YYYY-MM-DDTHH:mm" or "YYYY-MM-DD" (Bogotá local)
  end?: string;
  evening: boolean;              // starts ≥ 18:00
  venue: { name: string; address?: string; zone: "norte" | "centro" | "occidente" | "sur" | "desconocida" };
  nearHome: boolean;             // zone norte (Usaquén / Chapinero norte / Suba oriental)
  price: { free: boolean; text: string };
  accessibility: {
    walking: "poca" | "moderada" | "mucha" | "desconocida";   // vs ~300 m
    seating: boolean | null;     // seats available during the activity
    wheelchair: "si" | "parcial" | "no" | "desconocido";
    note: string;                // ≤ 160 chars, Spanish, concrete ("Auditorio con sillas; ascensor en la entrada")
  };
  forSeniors: boolean;           // aimed at persona mayor
  url: string;
  source: string;                // source id
  sourceName: string;
  image?: string;
};

type Place = {
  id: string; name: string; summary: string; category: Event["category"];
  address: string; zone: Event["venue"]["zone"]; nearHome: boolean;
  hours: string;                 // free text, Spanish
  price: { free: boolean; text: string };
  accessibility: Event["accessibility"];
  url: string;
};
```

## Frontend requirements

- Month grid (Mon–Sun) on desktop/tablet; agenda list on phones (< 700 px). Prev/next month, "Hoy".
- Big type (base ≥ 19 px), high contrast, large tap targets (≥ 48 px). Warm, calm look.
- Colour by `kind` (asistir vs participar) + emoji per category (🎨 arte, 🖌️ pintura, 💃 danza, 🎵 música, 🎭 teatro, 🎬 cine, 🌿 naturaleza).
- `span: "range"` events (exhibitions) shown in an "En exposición este mes" section, not in every cell.
- Filters: Asistir / Participar, Gratis, Cerca de casa, Sin noche (hide 🌙), Para persona mayor.
- Event detail (modal/sheet) with deep link `#/evento/<id>` — opening that URL opens the event.
- Buttons: **Compartir por WhatsApp** (`https://wa.me/?text=` + encoded message incl. deep link),
  **Agregar a Google Calendar** (`https://calendar.google.com/calendar/render?action=TEMPLATE&text=…&dates=…&ctz=America/Bogota&details=…&location=…`),
  **Cómo llegar** (`https://www.google.com/maps/search/?api=1&query=…`), **Ver más** (source url).
- "Siempre disponible" section listing `places`.
- Footer: "Actualizado: <generatedAt>" in Spanish.
- Greeting: "Hola, Totoya 🌸".
- Loads `data/events.json`; falls back to `data/events.sample.json` if missing (local dev).
